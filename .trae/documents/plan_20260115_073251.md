# 问题分析

经过分析，我发现问题出在情绪标签的格式上：

1. 系统要求AI模型以 `[EMOTION:情绪类型]` 格式输出情绪标签
2. 但从用户反馈的例子看，AI模型直接在文本末尾添加了纯文本形式的情绪词 "neutral"
3. 现有的 `remove_emotion_tag` 方法只能移除 `[EMOTION:xxx]` 格式的标签，无法处理纯文本形式的情绪词

# 修复方案

1. **修改 `ai_conversation.py` 中的 `remove_emotion_tag` 方法**：
   - 扩展正则表达式，使其能够识别和移除末尾的纯文本情绪词
   - 确保处理各种可能的情绪词格式

2. **具体修改点**：
   - 在 `ai_conversation.py` 第54行，修改正则表达式
   - 添加对纯文本情绪词的处理
   - 确保保持与现有功能的兼容性

3. **验证步骤**：
   - 确保能够正确移除 `[EMOTION:neutral]` 格式的标签
   - 确保能够正确移除直接附加的 "neutral" 情绪词
   - 确保不会影响正常的文本内容

# 预期效果

修复后，系统将：
- 正确处理格式化的情绪标签 `[EMOTION:xxx]`
- 正确处理直接附加的纯文本情绪词
- 确保前端显示和历史对话中不包含任何形式的情绪词
- 保持情绪信息的正确提取和传递
