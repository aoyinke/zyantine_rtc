# WebSocket连接和语音合成问题修复计划

## 问题分析

1. **WebSocket连接错误**：
   - 错误信息："WebSocket error: WebSocket is not connected. Need to call 'accept' first."
   - 原因：WebSocket端点函数没有正确调用`await websocket.accept()`来接受连接
   - 当前的`connect`方法中没有调用accept

2. **语音合成失败**：
   - 后端返回交互内容后，没有正常合成语音
   - 可能是因为WebSocket错误导致后续的语音合成逻辑没有执行
   - 也可能是语音合成流程本身存在问题

## 修复方案

### 1. 修复WebSocket连接流程

**修改点**：`ConnectionManager`类的`connect`方法

**修复内容**：
- 在`connect`方法中添加`await websocket.accept()`调用
- 确保WebSocket连接被正确接受
- 处理连接建立过程中可能出现的错误

### 2. 增强WebSocket状态检查

**修改点**：`send_message`方法

**修复内容**：
- 添加WebSocket状态检查
- 确保只在连接活跃时发送消息
- 提供更详细的错误日志

### 3. 优化语音合成错误处理

**修改点**：`process_speech_and_respond_stream`函数的语音合成部分

**修复内容**：
- 添加更详细的日志记录
- 确保语音合成失败时能正确处理
- 确保在WebSocket错误后能恢复正常流程

### 4. 改进日志记录

**修改点**：所有相关函数

**修复内容**：
- 添加更详细的日志记录
- 确保在关键节点都有日志输出
- 便于调试和追踪问题

## 修复代码示例

### 修改`connect`方法

```python
async def connect(self, websocket: WebSocket) -> str:
    # 接受WebSocket连接
    await websocket.accept()
    session_id = session_manager.create_session(websocket)
    self.active_connections[websocket] = session_id
    return session_id
```

### 修改`send_message`方法

```python
async def send_message(self, message: dict, websocket: WebSocket) -> bool:
    try:
        # 检查连接是否仍然活跃
        if websocket not in self.active_connections:
            logger.debug(f"WebSocket not in active connections, cannot send message")
            return False
        
        await websocket.send_json(message)
        return True
    except Exception as e:
        logger.error(f"Error sending message: {e}")
        # 从活跃连接中移除无效连接
        if websocket in self.active_connections:
            self.disconnect(websocket)
        return False
```
