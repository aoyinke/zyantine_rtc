# Live2D前端人物形象实现方案

## 方案概述
使用Live2D技术为前端界面添加一个交互式的2D角色形象，该角色能够响应鼠标移动、点击等操作，并在AI回复时展示相应的动画效果。

## 技术选型
- **Live2D库**：使用 `live2d-widget` 库，它是一个轻量级的Live2D集成方案
- **Vue3集成**：创建Vue3组件封装Live2D功能
- **模型转换**：将用户提供的cmo3格式模型转换为网页可用的格式

## 实施步骤

### 1. 模型转换准备

用户提供的模型是 `hiyori_movie_pro_zh`，包含以下文件：
- `hiyori_movie_pro_t02.cmo3` - Live2D Cubism Editor模型文件
- `hiyori_movie_pro_t02.can3` - Live2D Cubism Editor动画文件
- `background.jpg` - 背景图片

由于这些是Live2D Cubism Editor的原生格式，需要转换为网页可用的格式。

### 2. 安装依赖

在 `vue3-frontend` 目录下执行以下命令：

```bash
npm install live2d-widget
```

### 3. 创建Live2D组件

在 `src/components` 目录下创建 `Live2DCharacter` 文件夹，并创建以下文件：

#### `Live2DCharacter.vue`

```vue
<template>
  <div class="live2d-container" ref="live2dContainer"></div>
</template>

<script setup>
import { ref, onMounted, onUnmounted, watch } from 'vue'
import { useChatStore } from '../../stores/chat'

const live2dContainer = ref(null)
const chatStore = useChatStore()
let live2dWidget = null

// 初始化Live2D
onMounted(() => {
  import('live2d-widget').then(module => {
    const { init } = module
    
    live2dWidget = init({
      el: live2dContainer.value,
      width: 300,
      height: 400,
      model: {
        // 使用官方提供的免费模型，后续可替换为用户转换后的模型
        jsonPath: 'https://cdn.jsdelivr.net/npm/live2d-widget-model-shizuku@1.0.5/assets/shizuku.model.json'
      },
      display: {
        position: 'right',
        width: 300,
        height: 400,
        hOffset: 0,
        vOffset: -20
      },
      mobile: {
        show: true,
        scale: 0.8
      },
      react: {
        opacityDefault: 0.8,
        opacityOnHover: 0.9
      }
    })
    
    // 监听状态变化，触发相应动画
    watch(
      () => chatStore.status,
      (newStatus) => {
        handleStatusChange(newStatus)
      }
    )
  })
})

// 处理状态变化
function handleStatusChange(status) {
  switch (status) {
    case 'recording':
      // 录制时的动画
      live2dWidget?.speak('我在听呢...')
      break
    case 'processing':
      // 处理时的动画
      live2dWidget?.speak('正在识别...')
      break
    case 'generating':
      // 生成时的动画
      live2dWidget?.speak('正在思考...')
      break
    case 'synthesizing':
      // 合成时的动画
      live2dWidget?.speak('正在准备语音...')
      break
    case 'playing':
      // 播放时的动画
      live2dWidget?.speak('')
      break
  }
}

// 销毁Live2D实例
onUnmounted(() => {
  if (live2dWidget) {
    live2dWidget.destroy()
    live2dWidget = null
  }
})
</script>

<style scoped>
.live2d-container {
  position: fixed;
  bottom: 20px;
  right: 20px;
  z-index: 1000;
  width: 300px;
  height: 400px;
  pointer-events: auto;
}

@media (max-width: 768px) {
  .live2d-container {
    width: 200px;
    height: 267px;
    bottom: 10px;
    right: 10px;
  }
}
</style>
```

### 5. 模型转换指南

由于用户提供的是 `cmo3` 格式的模型文件，需要使用Live2D Cubism Editor转换为网页可用的格式：

#### 步骤1：下载并安装Live2D Cubism Editor
- 访问 [Live2D官方网站](https://www.live2d.com/zh-CHS/download/cubism/) 下载Live2D Cubism Editor
- 安装并打开软件

#### 步骤2：导入模型
- 在Live2D Cubism Editor中，选择「文件」→「打开」，选择 `hiyori_movie_pro_t02.cmo3` 文件

#### 步骤3：导出为网页格式
- 选择「文件」→「导出为运行时文件」
- 选择「Web」平台
- 设置导出路径，生成 `model.json` 文件和相关资源

#### 步骤4：部署模型文件
- 将导出的模型文件复制到 `vue3-frontend/public/live2d-models` 目录下
- 目录结构示例：
  ```
  public/
  └── live2d-models/
      └── hiyori/
          ├── model.json
          ├── textures/
          │   └── texture_00.png
          └── motions/
              └── idle_00.json
  ```

#### 步骤5：修改组件配置
- 更新 `Live2DCharacter.vue` 中的 `jsonPath` 为自定义模型路径：
  ```javascript
  jsonPath: '/live2d-models/hiyori/model.json'
  ```

## 预期效果

- **视觉效果**：界面右侧底部显示一个生动的Live2D角色，能够响应鼠标操作
- **交互效果**：角色会根据对话状态展示不同的表情和动画
- **响应式**：在移动设备上自动调整大小和位置
- **性能优化**：使用按需加载，不影响页面加载速度

## 注意事项

1. **模型加载**：首次加载模型可能需要一些时间，请确保网络连接稳定
2. **性能消耗**：Live2D动画可能会消耗一定的CPU资源，建议在低配置设备上适当降低动画复杂度
3. **版权问题**：使用自定义模型时，请确保拥有相应的版权或使用免费模型
4. **兼容性**：部分浏览器可能对Live2D支持有限，建议在主流浏览器中测试
