# 修复Live2D人物位置问题

## 问题分析

通过代码分析，我发现Live2D人物位置不正确的主要原因包括：

1. **元素移动逻辑问题**：使用`setTimeout`延迟1秒后移动live2d元素到容器中，这个过程可能导致位置不准确
2. **默认定位冲突**：live2d-widget.js库默认会在页面右下角创建模型，然后我们手动移动它
3. **容器样式问题**：当前的容器样式和模型大小可能不匹配
4. **定位精度问题**：移动元素后的样式设置可能不够精确

## 解决方案

### 方案1：改进Live2DCharacter组件实现

1. **修改元素移动逻辑**：
   - 移除setTimeout延迟，使用更直接的方式获取和移动元素
   - 添加更精确的样式控制，确保模型在容器中正确定位

2. **调整容器样式**：
   - 修改live2d-container的尺寸和定位方式
   - 确保容器在页面上方正确显示

3. **优化模型配置**：
   - 调整模型的初始位置和大小
   - 确保模型在容器中居中显示

### 方案2：使用更直接的Live2D初始化方式

1. **替换live2d-widget.js**：
   - 使用更轻量级的方式直接初始化Live2D模型
   - 避免默认定位行为的影响

2. **自定义定位逻辑**：
   - 完全控制模型的创建和定位过程
   - 确保模型在页面上方正确显示

## 实施步骤

1. **修改Live2DCharacter组件**：
   - 改进元素移动逻辑，移除setTimeout
   - 调整容器和模型的样式设置

2. **优化App.vue布局**：
   - 确保avatar-section在页面上方正确显示
   - 调整容器大小和间距

3. **测试和调整**：
   - 验证Live2D人物在不同屏幕尺寸下的显示效果
   - 微调位置和大小以达到最佳效果

## 预期效果

修复后，Live2D人物应该：
- 正确显示在页面上方的avatar-section中
- 在容器中居中显示，大小适中
- 在不同屏幕尺寸下都能正确适配
- 与页面其他元素保持良好的视觉平衡
