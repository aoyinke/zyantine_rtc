# 修正右侧人物模型位置方案

## 问题分析
- 右侧人物模型视觉上位置太偏右侧，需要调整使其居中显示
- 目前模型位置设置在容器中心（`width / 2, height / 2`），但由于模型原点或设计原因，视觉上不居中

## 解决方案
修改 `Live2DAvatar.vue` 组件中的模型位置设置，向左微调模型的X坐标，使其在视觉上居中。

## 具体修改步骤
1. **修改 `loadModel` 函数**（第93行）：
   - 将模型X坐标从 `width / 2` 调整为 `width / 2 - 50`（具体值可根据实际效果调整）

2. **修改 `resizeModel` 函数**（第121行）：
   - 同样将模型X坐标从 `width / 2` 调整为 `width / 2 - 50`

3. **测试调整效果**：
   - 运行项目查看模型位置是否居中
   - 如果仍有偏差，微调X坐标的偏移值

## 预期效果
- 右侧人物模型在视觉上居中显示，不再偏右
- 保持模型的其他功能不变
- 确保在不同屏幕尺寸下都能正确显示
